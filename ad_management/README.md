# Zooz Ad Management

Welcome to the **Zooz Ad Management** (Ads Manager) system directory. This hub outlines the advertising protocols, target segmentation engines, custom tracking pixels, and analytics dashboards that power commercial reach on the Zooz social ecosystem.

## Core Features
1. **Ad Campaign Builder**: Configuration structures for Objective-Based Campaigns (Awareness, Traffic, Engagement, Sales, Lead Generation).
2. **Zooz Pixel (Tracking)**: A lightweight client-side script for tracking conversions, page views, and specific custom actions on external merchant sites (e.g. Next.js Marketplace).
3. **Audience Demographics Segmenter**: Algorithms to group users by local preference, interest indices, and social activity tags.
4. **Billing & Budget Orchestrator**: Interface guidelines for daily/lifetime budget caps, bidding algorithms, and micro-billing transaction pipelines.

## Folder Structure
- `/pixel` - Embedding code block scripts and server-side webhook endpoints.
- `/pixel-helper` - Developer chrome-extension simulation resources for pixel validation.
- `/campaigns` - Schema formats for storing and modifying reactive ad-sets.
